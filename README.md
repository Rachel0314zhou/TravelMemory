# 旅迹本 (TravelMemory) —— 旅行记录与回忆卡片生成 App

“旅迹本”（TravelMemory）是一款专为旅行爱好者打造的、完全本地化的、轻量离线个人旅行手账与回忆纪念卡片生成工具。
本项目完全使用 **Java 语言** 进行原生开发，界面使用 **XML 布局文件** 编写，架构采用经典的 **MVC 模式**，本地数据存储完全依赖原生 **SQLite 数据库**，不依赖任何外部联网 API、后端服务、Firebase 或 AI 接口，支持 100% 离线顺畅运行。

---

## 一、 项目核心文件与角色说明

应用代码结构清晰明了，各层次模块职责明确：

### 1. 引导与主控页面 (`activity` 包)
*   **`SplashActivity.java` (欢迎/引导页)**: 检测本地用户状态，首次运行提供精致的中国风昵称输入表，保存后进入主控台；之后运行自动展示欢迎语并延时跳转。
*   **`MainActivity.java` (旅行长廊主界面)**: 检索并瀑布流展示已记录的所有旅行，包含昵称问候语、便捷搜索入口、新建旅行的悬浮按钮（FAB）。
*   **`AddTripActivity.java` (卡片编辑/添加)**: 覆盖旅行名称、目的地、开始与结束时间的表单。集成本地日历选择器，提供相册导入和调用相机拍照剪切，并能在退出或修改时更新。
*   **`TripDetailActivity.java` (时光轨迹详情)**: 显示旅行的顶部大图、地点等元素。同时集成 **照片数**、**打卡景点数**、**总支出** 等三大实时统计面板；底部以 **时间轴 (Timeline) 形式** 呈现每日随手日记。

### 2. 旅行细项管理页面 (`activity` 包)
*   **`DayRecordActivity.java` (随笔日记撰写)**: 提供开心 😊、平静 😐、疲惫 😴、兴奋 🤩、感动 🥹、遗憾 😔 六种心情 Emoji 单选。保存时智能进行覆盖/更新，并展示高亮颜色标签。
*   **`PhotoActivity.java` (行囊相册管理)**: 渲染 3 列网格图片墙，支持直接调用系統相机拍摄即刻保存，或从系统相册批量移入，点击照片即刻弹窗无缝全屏预览。
*   **`SpotsActivity.java` (景点打卡标记)**: 集成打卡登记面板。包括地名输入、打卡类型下拉选择器（美食、风景等），以及“心动标记（最爱）”星标切换。
*   **`ExpenseActivity.java` (支出记账手账)**: 实时总账单统计。自动计算各大类目（餐饮、住宿、交通等）子项总支出并展示比例账目，支持多币种数值运算與滑动删除。
*   **`SearchActivity.java` (全文引擎检索)**: 提供统一的搜索面板。支持按地名/日记文字模糊搜索，或通过点击顶部 Mood 水平滑块，过滤特定情感旅行。
*   **`MemoryCardActivity.java` (回忆紀念卡生成)**: 核心高光页面。它把封面、周期、天数、以及精要统计数值、日记和彩蛋集成到明信片中，通过 **Canvas 技术** 将视图在本地直接转绘为高保真图片，保存至本地并拉起 **FileProvider 分享** 交互。

### 3. 数据层与辅助类 (`db` 与 `utils` 包)
*   **`DatabaseHelper.java` (本地 SQLite 数据核心)**: 构建 6 张核心数据表 (`user`, `trip`, `day_record`, `photo`, `spot`, `expense`)。提供了 100% 离线的增删改查及统计聚合算法。**在首次安装启动时，会自动初始化一段极其精美的“厦门行”展示级仿真伪测试数据。**
*   **`ImageUtils.java` (极轻影像传输核心)**: 实现照片高保真抗 OOM 载入。在导入相册或拍照完成时，**执行全拷贝操作：将源图片转储至应用私有存储沙盒 `MainActivity.this.getFilesDir() + "/photos/"` 下，数据库仅存放本地绝对路径**，不依赖临时 `content://` URI 避免断电或重启权限解封失败。
*   **`MemoryCardUtils.java` (智能彩蛋生成器)**: 编写了多重条件的触发控制算法，自动在生成回忆卡片时奉上暖心评价：
    *   *条件一*：消费超过 ¥2000 ➡️ 触发 “壕气冲天！这趟旅程你是一点没亏待自己...”
    *   *条件二*：打卡景点数 $\geq 3$ ➡️ 触发 “打卡达人！你把风景走成了地图上的星光...”
    *   *条件三*：照片记录 $\geq 3$ ➡️ 触发 “定格时光的魔术师，感谢你记录了这么多美妙瞬间...”
    *   *默认文案*：➡️ 触发 “随心而行，最美的风景永远在未知的下一站...”

## 二、 本地导入与运行指南 (Android Studio)

为保证项目可以直接加载并顺利运行，请按以下步骤操作：

### 1. 打开项目
1.  解压项目压缩包文件夹（确认包含 `/app` 子目录、`build.gradle.kts` 等）。
2.  启动您的 **Android Studio** (推荐 Hedgehog 2023 或更高级版本)。
3.  点击 **File -> Open**，选择解压出来的根文件夹，点击 **OK**。

### 2. Gradle 同步与配置
1.  Android Studio 将在右下角自动载入并开始 Gradle 构建。
2.  应用配置的 Minimum SDK 为 **API 23 (Android 6.0)**，Target SDK 为 稳定版 API 34。
3.  为了支持快速离线同步，项目排除了外部 Gradle 三方不确定仓库。所有控件完全基于自带的标准 AndroidX、Material 3 核心包，无需翻墙下载任何未授信包，同步将在 1-2 分钟内完成。

### 3. 运行应用
*   选择您的虚拟模拟器 (Emulator) 或真实外接 Android 手机。
*   点击顶部工具栏的 **Run 'app'** (绿色播放三角形按钮) 即可完成自动编译部署并呼出。

## 三、 本地相机/存储权限排查与推荐

应用已经完美兼容自 API 23 及以上级别的**权限动态申请**，如果使用过程中遇到无法打开相机或相册，请按以下指南排查：

1.  **应用自动申请**: 用户在“增加旅行”或“照片”页面点击 `拍照`、`从相册导入` 时，应用会自动调起系统的权限请求对话框。
2.  **真机/模拟器手动授权**:
    *   如果在系统对话框中误触了“拒绝且不再询问”，可返回模拟器桌面。
    *   长按 **“旅迹本”** 应用图标，在弹出的菜单中点击 **应用信息 (App Info)** 或感叹号。
    *   进入 **权限 (Permissions)** 管理面板，将 **相机 (Camera)** 和 **照片与视频 (Photos and videos)** 设为 **允许 (Allow)** 即可正常使用。

## 四、 课堂演示黄金路线 (建议 3-5分钟)

为了完美的向老师和同学们展示，我们硬编码内置了一套最抓眼球的展示流程，无需提前手动录入，安装即可开始惊艳的讲台演示：

### 🎬 第一幕：首次邂逅，定下笔名
1.  **启动页闪现**: 运行应用，如果是新用户（或卸载重装），展示页面会在底部冉冉升起一个清秀的古风对话框：“在启程前，写下你的旅人昵称”。
2.  **自定义输入**: 示范输入昵称：**“小雅”**，点击 **开启旅意** 按钮。
3.  **心动问候**: 输入后，屏幕划过精美的微缩渐变过渡效果，瞬间抵达主面板，顶部横幅显示温馨问候：`你好，小雅`。

### 🎬 第二幕：内置名胜，引出数据
1.  **首选查看已有旅行**: 在主页列表，会惊艳地发现系统已经在初装时自动插入了一段名为 **“毕业前的厦门之旅”** 的厦门地标旅行卡片。
2.  **点击卡片进入**: 卡片包含目的地、起止时间等，点击整张卡片卡片，进入 `TripDetailActivity` (旅行时光轨迹)。页面顶部是精美的海景图。
3.  **亮眼的三大板块统计**: 
    - 屏幕中央有三大色块圆盘：**照片 (3张)** | **打卡 (3处)** | **总花费 (¥854.50)**。
    - 统计面板下，一条古雅的纵向时间轴 (Timeline Layout) 展现了第一天（沙坡尾）、第二天（鼓浪屿）、第三天（环岛路礁石）的心情日记，还配有一目了然的心情颜色贴纸。

### 🎬 第三幕：随手记账，景点登记
1.  **登记新花销**: 点击中部快捷入口的`记账明细`，进入账单管理。
    - 指导输入：金额 `80`。下拉框选择分类 `餐饮`。备注 `日光岩土笋冻与烧肉粽`，点击确认。
    - 观察变化：上方的 **总开销数值** 瞬间从拉取出的本地数据增加到了 `¥ 934.50`。其分类下的“餐饮”小总计数据也跟着瞬时变动！
2.  **新增日记/景点**: 依此点击`景点打卡`，输入 `演武大桥`，设置打卡类型 `特色街道`，勾选 `标记最喜欢`，点击确认。

### 🎬 第目：高光时刻，生成“旅迹卡片”并分享
1.  **回忆卡生成**: 返回详情页面，此时 📸 **照片 = 3**、📍 **景点 = 4**、💰 **总金额 = ¥934.50**。点击最后一个高亮金橙色的巨型按钮 —— **🌟 生成回忆纪念卡**。
2.  **渲染回忆明信片**: 页面会展示明信片：包含了旅行数据、精选的长微博日记，以及底部的**金色暖心彩蛋评价**：
    *   *(此时打卡景点数=4，且照片=3，花费未足2000。触发彩蛋)*：**“打卡达人！你把风景走成了地图上的星光...”**！
3.  **拉起无网分享**: 点击底部的“生成分享图片”按钮，应用会瞬间以最底层的 native canvas 将这个卡片绘制成图，通过 FileProvider 优雅呼出自带的系统分享，显示“正在从本地分享回忆明信片...”画面，完美无暇地结束课堂教学演示！
